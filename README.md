# go-sales

실무형 B2B 영업을 AI 튜터와 함께 익히는 학습 워크스페이스입니다. 과학적 파이프라인 관리, 리드 관리, 대고객 어프로치(디스커버리·SPIN·Challenger·MEDDPICC·Solution Selling), 스토리 기반 영업, 마피아 제안, 제안서·협상·클로징, 계약 후 확장, 영업 조직·KPI·보상을 다룹니다. 국내 법령(공정거래법·하도급법·정보통신망법·청탁금지법·국가계약법 등)이 뼈대이고, 글로벌 기준은 비교 축입니다.

정해진 강의 자료는 없습니다. 이 리포에는 커리큘럼의 큰 지도와 튜터의 행동 규칙만 있습니다. 도식과 조사 자료를 조합한 HTML은 대화하면서 튜터와 함께 그 자리에서 만듭니다. 실습은 내 실제 상품·고객·딜로 합니다.

## 시작하기

준비물은 Git, [GitHub CLI](https://cli.github.com)(`gh`), Claude Code 또는 Claude Desktop입니다. 공개 리포라 초대 없이 받을 수 있습니다. 터미널에서 `gh auth login`으로 한 번 로그인합니다. 다른 설치는 필요 없습니다.

```bash
cd ~/Desktop
gh repo clone holmesLee-ws/go-sales
```

**Claude Code**

```bash
cd ~/Desktop/go-sales
claude
```

처음 열면 이 폴더를 신뢰하는지 묻습니다. 기본 선택은 「No, exit」이므로 Enter만 누르면 종료됩니다. **아래 화살표로 「Yes, I trust this folder」를 고른 뒤 Enter**를 누르세요. 그래야 학습 기록 저장과 자료 조사를 튜터가 묻지 않고 진행합니다.

**Claude Desktop**

Code 탭에서 데스크탑의 `go-sales` 폴더를 선택합니다. Chat 탭이 아니라 Code 탭이어야 튜터 규칙이 적용됩니다.

어느 쪽이든 「안녕」이라고 입력하면 시작합니다.

## 이렇게 진행됩니다

1. 왜 배우려는지, 지금 무엇을 누구에게 파는지 묻고, 세 묶음(파이프라인·리드 / 대고객 어프로치 / 제안·클로징·계정)마다 상황 문제를 하나씩 풀어 출발점을 찾습니다. 영업이 처음이면 이 단계는 생략합니다.
2. 모듈마다 먼저 딜 상황 문제로 수준을 확인합니다. 이미 아는 내용이면 바로 넘어갑니다. 경력이 길다는 말만으로는 넘어가지 않습니다.
3. 필요한 부분은 튜터와 대화하고 역할극을 하며, 튜터가 내 답을 반영한 HTML을 만들어 가며 익힙니다. 진단표·제안서 같은 산출물은 내가 직접 쓰고 튜터가 짚습니다.
4. 튜터는 내 답을 보고 너무 빠른지, 보강이 필요한지, 지루한지 판단해 속도와 방식을 바꿉니다.
5. 다음에 다시 열면 기록을 읽고 이어갑니다. 복습할 때가 된 모듈이 있으면 복습 질문 하나부터 냅니다.
6. 졸업 프로젝트는 내 업무에 바로 쓸 세 가지입니다: 파이프라인 진단표, 제안서, 마피아 제안 초안.

언제든 말로 요청하면 됩니다. 「이건 넘어가자」, 「너무 어려워」, 「고객 역할 해 줘」, 「그림으로 보여 줘」처럼요.

| 명령 | 하는 일 |
|---|---|
| `/learn [모듈 또는 주제]` | 시작하거나 이어가기 |
| `/check [모듈 또는 영역]` | 빠르게 수준 확인하고 건너뛰기 |
| `/map` | 지금까지의 현황과 다음 모듈 |
| `/pace [너무 빠름·너무 느림·지루함·어려움]` | 속도와 난도 바꾸기 |

## 실제 고객 정보와 법률 판단

- 고객사명·담당자 이름·연락처·금액은 가명이나 범위로 바꿔서 말하세요. 학습 기록은 내 컴퓨터에만 남지만, 튜터가 웹을 조사할 때 질문이 외부 서비스로 전달됩니다.
- 튜터는 법령을 공식 출처(국가법령정보센터 등)에서 그 자리에서 찾아 보여 주지만 법률 자문이 아닙니다. 실제 딜의 적법성은 회사 법무나 변호사에게 확인하세요.

## 구성

| 위치 | 내용 |
|---|---|
| [curriculum/map.md](curriculum/map.md) | 커리큘럼 지도 |
| [CLAUDE.md](CLAUDE.md), [tutor/](tutor/) | 튜터의 행동 규칙 |
| `.claude/` | 명령과 권한 설정 |
| `learner-template/` | 학습 기록의 빈 양식 |
| `learner/` | 내 기록, 내 HTML(`studio/`), 내 산출물(`work/`). 처음 시작할 때 생깁니다 |
| [docs/build/](docs/build/) | 이 리포를 만든 기록과 근거 출처 |

`learner/`는 Git에서 제외되어 내 컴퓨터에만 남습니다. 그래서 `git pull`로 커리큘럼을 업데이트해도 기록이 충돌하지 않습니다. 컴퓨터를 옮길 때는 이 폴더를 직접 복사하세요.

## 튜터가 쓰는 권한

튜터는 묻지 않고 내 학습 기록, `learner/studio`의 HTML, `learner/work`의 산출물을 쓰고, 웹을 조사하고, 만든 HTML을 열 수 있습니다. 그 밖의 파일을 고칠 때는 평소처럼 허락을 구합니다.
